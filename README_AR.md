# العنكبوت الحي 🕷 — Live Spider
تطبيق أندرويد (Kotlin) — عنكبوت واقعي يتجول على الشاشة الرئيسية، يتفحص أيقونات التطبيقات، وينسج شبكة في زاوية الشاشة. يتخذ قراراته عبر Gemini 3.8 Flash (`gemini-3.8-flash`).

المطوّر: خضر أبو صالحه (khader abo salha) — mankhader@gmail.com

## البناء من الهاتف فقط (بدون كمبيوتر)
1. أنشئ مستودعاً جديداً على github.com (من متصفح الهاتف).
2. ارفع كل محتويات المجلد (Add file ← Upload files). تأكد أن المجلد المخفي `.github/workflows/build.yml` وصل؛
   إن لم يصل: Add file ← Create new file واكتب الاسم `.github/workflows/build.yml` والصق محتوى الملف.
3. تبويب Actions ← Build APK ← Run workflow (أو يبدأ تلقائياً عند الرفع). يستغرق ~4 دقائق.
4. بعد النجاح: افتح تبويب Releases ← حمّل `SpiderPet.apk` وثبّته.

## أول تشغيل
1. افتح التطبيق ← «الظهور فوق التطبيقات» ← منح.
2. «خدمة إمكانية الوصول» ← فعّل «العنكبوت الحي» (إن كان رمادياً: معلومات التطبيق ← ⋮ ← السماح بالإعدادات المقيّدة).
3. الإعدادات ← الصق مفتاح Gemini من aistudio.google.com/apikey ← اختبار الاتصال.
4. اضغط «تشغيل العنكبوت» واذهب للشاشة الرئيسية.
